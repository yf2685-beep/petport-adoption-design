# Petport — Pet Adoption Product Design

Personal portfolio fork of [the original team repository](https://github.com/swe-students-fall2025/1-specification-byteme). Team authorship and course history are preserved.

**宠物领养产品设计：从用户需求和产品愿景，到用户故事、流程图和可交互原型。**

Petport is a course product-design project that brings pet discovery, trustworthy profiles and shelter communication into one proposed mobile experience. This repository contains requirements and prototypes; it is a specification-stage project.

## The problem and the proposed experience

Adopters encounter scattered listings, uncertain availability and fragmented conversations. Shelter staff need to maintain listings and handle requests with limited time. Petport proposes a shared workflow:

**Browse and filter → inspect a pet profile → save or contact the shelter → submit an application → follow the status.**

| User need | Product response |
| --- | --- |
| Find a suitable pet | Species, age, size, breed and location filters |
| Make an informed decision | Profiles with photos, temperament and health information |
| Return to promising matches | Favorites and saved preferences |
| Resolve questions | In-app messages and reply notifications |
| Reduce shelter administration | Listing/status updates and a consolidated request view |
